# Echo360 Track Downloader

Echo360 の授業ページで、閲覧権限のある映像・音声トラックを検出して保存する Chrome 拡張機能です。

## インストール

1. Chrome で `chrome://extensions` を開く。
2. 「デベロッパー モード」を有効にする。
3. 「パッケージ化されていない拡張機能を読み込む」を選ぶ。
4. このリポジトリのフォルダを選ぶ。

## 使い方

1. Echo360 の授業ページを開く。
2. 動画を数秒再生する。
3. ツールバーの拡張機能アイコンを開く。
4. 品質を選び、Source 1/2 の映像と同じ品質の音声を保存する。

Echo360 の実測配信は映像と音声が別々の fragmented MP4 です。現在のMVPはトラックを確実に保存するところまでを担当し、muxは行いません。

## プライバシー

- 通信は外部サービスへ送信しません。
- 認証CookieやJWTを読み取りません。
- 署名・識別queryを含む完全URLはディスクへ永続化されないセッション領域だけに保持し、タブを閉じると破棄します。
- Echo360上で閲覧・ダウンロードを許可されたコンテンツにのみ使用してください。
