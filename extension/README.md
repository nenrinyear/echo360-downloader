# Chrome extension

Chrome の `chrome://extensions` でデベロッパーモードを有効にし、この `extension` ディレクトリを「パッケージ化されていない拡張機能」として読み込んでください。

Echo360 の動画を数秒再生すると、Source 1、Source 2、音声と利用可能な品質を検出します。音声と少なくとも一方の映像Sourceが揃うと、CLI用の `echo360.json` を含む講義フォルダを作成できます。

section の `/home` ページでは、一覧中の授業リンクを検出して「一覧を全てダウンロード」を表示します。押すと授業をバックグラウンドタブで順番に開き、検出できた最高品質の映像・音声トラックと `echo360.json` を講義ごとに保存します。
